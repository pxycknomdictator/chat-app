# Chat App (MERN + TypeScript + Socket.io)

A real-time chat app built with MERN, TypeScript, and Socket.io, featuring JWT authentication and MongoDB storage. Supports instant messaging with a responsive UI. 🚀

## Features

- 🔹 Real-time messaging with Socket.io
- 🔹 User authentication using JWT
- 🔹 MongoDB for data storage
- 🔹 Responsive UI with Tailwind CSS

## Tech Stack

- **Frontend:** React, TypeScript, Tailwind CSS
- **Backend:** Node.js, Express.js, TypeScript, Socket.io
- **Database:** MongoDB with Mongoose

## Installation

1. **Clone the repository:**

   ```sh
   git clone https://github.com/pxycknomdictator/chat-app.git
   cd chat-app
   ```

2. **Install dependencies:**

   ```sh
   cd client && npm install
   cd ../server && npm install
   ```

3. **Set up environment variables:**  
   Create a `.env` file in the server and client directory .

4. **Run the application:**
   ```sh
   cd server && npm run dev
   cd ../client && npm run dev
   ```
